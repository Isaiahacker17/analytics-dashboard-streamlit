# Analytics Dashboard & Data Pipeline

Built using Python, Pandas, and Streamlit.

## Overview

This project demonstrates a basic analytics workflow and ETL concepts using Python.

Data Source → Transformation → KPI Calculation → Visualization

## Features

- KPI Cards
- Traffic Source Analytics
- State Analytics
- Device Analytics
- Interactive Filters
- Derived Metrics
- Streamlit Dashboard

## Technologies

- Python
- Pandas
- Streamlit
- Git
- GitHub

## Concepts Demonstrated

- ETL (Extract, Transform, Load)
- Data Transformation
- Data Aggregation
- KPI Development
- Dashboard Design

## Architecture

CSV Data
↓
Pandas DataFrame
↓
Transformations
↓
Aggregations
↓
KPI Generation
↓
Interactive Dashboard
